# Идея проекта
GradeBot сможет помочь в отслеживании успеваемости.

Он будет получать актуальную информацию по оценкам и иметь различные функции для работы с оценками.

Пользователь сможет не только смотреть свои оценки, но и сравнивать их с оценками других учеников,
а также узнавать предметы по которым выходит спорный балл, и все это в понятной форме.

Удобный интерфейс обеспечит пользователя инструциями и поможет получить оценки в струтурированной виде


# Backend

## Какие функции стоит реализовать
1. Получение всех оценок, сгрупированных по предметам, по personId
2. Получение оценок по конкретному предмету по personId
3. Добавить средний и средний взвешенный баллы
4. Получение списка учеников и их оценок со средним и средним взвешенным баллами по каждому или по одному предмету
5. Считать ср балл по предмету среди всех, сравнивать со своим и показывать разницу, например Физика = 4,5 — +0,8 от среднего по классу
6. Сделать специальное меню где показывается отношение моего ср балла к общему ср баллу класса под каждый предмет
7. Считать кол-во пятерок до повешения балла выше 4,5 или кол-во четверок/троек до понижения балла ниже 4,5
8. Используя прошлые подсчеты выявлять предметы по которым уже трудно изменить балл или по которым спорный балл

## Как устроена программа

### Абстрактно
- Главный файл main.py подключает роутеры и запускает периодическое обновление бд
- Все функции для работы с бд лежат в 1 файле и импортируются другими модулями
- Хэндлеры импортируют функции для получения даных, обрабатывают сообщения и отвечают за красивый вывод
- Отдельный файл импортирует функции обновления данных, получает актуальную информацию и обновляет бд

### Реальная структура
1. main.py - Главный файл
2. updater.py - Получение актуальных данных из дневника
3. sessional_logs.log - Сессионные логи программы
4. middlewares/ - Промежуточный код. Проверка существования пользователя и статус бана
5. testing/ - Функции, необходимые для тестирования
6. data/ - Базы данных и другие данные
7. keyboards/ - Функции сборки клавиатур

        reply_menus.py - Различные reply-меню
        confirm.py - Клавиатуры подтверждений

8. handlers/ - Обработчики событий

        profile.py - Профиль пользователя
        personal_grades.py - Персональные оценки
        general_grades.py - Общие оценки
        avg_and_wa.py - Средние и средние взвешенные баллы
        subject_more.py - Подробнее по предмету
        ✔ dnevnik_connection.py - Подключение, активация и деактивация дневника
        fallbacks - Последние обработчики ловящие все

9. database/ - Функции работы с бд

        ✔ initialization.py - Инициализация всех таблиц и заполнение дефолтных значений - названия ролей и их права
        ✔ update_school_data.py - Обновление всех школьных данных - оценок, учеников, предметов уроков и тп
        get_own_school_data.py - Получение школьных данных конкретного ученика. Множество специфических функций
        get_other_school_data.py - Получение школьных данных всех учеников. Множество специфических функций
        ✔ dnevnik_relations.py - Связывание дневника - добавление связи, ее активация и деактивация
        ✔ user_management.py - Управление пользователями - добавление
        ✔ verifications.py - Различные проверки банов, ролей и прав
        admin_control.py - Админские функции для управления пользователями - бан, изменение ролей
        get_internal_data.py - Получение внутренних данных - бан лист или активные пользователи с tg_id и person_id

## Примерный алгоритм запросов
1. Делаем запрос edu-groups/{group}/subjects и Полностью заполняем таблицу subjects
2. Делаем запрос edu-groups/{group}/persons и Полность заполняем таблицу persons
3. Делаем запрос edu-groups/{group}/marks/{from}/{to} и Полностью заполняем таблицу marks
4. Делаем запрос work-types/{school} и Полностью заполняем таблицу work-types
5. Делаем запрос edu-groups/{group}/lessons/{from}/{to} и Полность заполняем таблицу lessons
6. Используя результаты прошлого запрос, Полностью заполянем таблицу works

# Frontend

## Инструкции

| Команда | Действие |
| ------- | -------- |
| /start | Запуск бота и приветственное сообщение сразу с кнопками действий, таких как "Посмотреть все оценки" или "Заглянуть в профиль" |
| /help | Вызов справки |
| /home, /menu | Начальное меню |
| /update | Обновить базу данных актуальной информацией |
| /profile | Открыть профиль |
| /settings | Открыть настройки |
| /myrole | Узнать свою роль |
| /changerole | Изменить роль |
| /bun | Забанить пользователя |
| /bunlist | Список банов |

## Интерфейс
По команде /start пользователь получает приветственное сообщение с ссылкой на инструкции и кнопками.
Эти же кнопки и по команде /menu но с другим текстовым сообщением

"Мои оценки", "Все оценки", "Оценки других", "Мой профиль", "Настройки"

# Дополнительно

- Через объект bot, зная telegram_id пользователя можно узнать информацию о пользователе с помощью bot.get_chat(chat_id=user_id)
- Через объект chat можно получить некоторую информацию, к примеру chat.pinned_message или chat.bio
- message.date - время отправки сообщения
- message.chat - объект Chat
- chat.id равен telegram_id пользователя
- bot.send_message(chat_id, text) - отправить сообщение в любой чат зная chat_id или telegram_id
- Роли: creator, moder, user, guest
- Может быть новая таблица users_accounts в которой связываем telegram_id и person_id
- Остается только придумать проверку или же заполнять вручную
- Искать person_id юзера каждый раз в middleware
